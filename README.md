# Antenna-Array-Analysis-and-Optimization

The assignment was part of the course Antennas &amp; Propagation (Electrical &amp; Computer Engineering, Aristotle University of Thessaloniki).
This repository contains all MATLAB implementations for analyzing, modeling, and optimizing various antenna array configurations, the resulting diagrams and the final report for the project.

## Overview
### 1. Analysis of Two-Dimentional 24 $\times$ 12 Antenna Array
- Radiation Pattern (horizontal, vertical & 3D) for different main lobe angles
- Analytical and numerical directivity calculation
- Analysis of end-fire & end-fire Hansen-Woodyard array (radiation patterns & directivity calculation)

### 2. Directivity of linear, non-uniform Array
- Analytical proof of the directivity formula for an N-element linear, non-uniform array

### 3. Non-Uniform Array Design via Optimization Techniques
- Single-objective optimization to achieve target Side Lobe levels
- Multi-objective genetic algorithm optimization to balance minimum Side Lobe levels and maximum Directivity (Pareto Front)

### 4. Input Impedance & Mutual Coupling Analysis
- Mutual impedence calculation between two parallel $\lambda/2$ dipoles
- 3-dipole system analysis (1 active, 2 parasitic elements) to evaluate input impedance and reflection coefficient
- 1D and 2D parametric sweeps (including a reflector/infinite ground plane) to identify operational regions where reflection coefficient is under a desired limit
